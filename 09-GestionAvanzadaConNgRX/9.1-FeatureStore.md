# Feature Store
Depurar el estado de una aplicación gestionada con NgRx puede ser desafiante, especialmente en proyectos grandes. Afortunadamente, `@ngrx/store-devtools` proporciona herramientas para visualizar y depurar el estado de la tienda en tiempo real. Estas herramientas permiten rastrear acciones, estados y efectos con facilidad, mejorando significativamente la experiencia de desarrollo.

## ¿Qué es @ngrx/store-devtools?
`@ngrx/store-devtools` es un complemento de NgRx que se integra con herramientas de desarrollo como Redux DevTools (disponible para Chrome y Firefox). Esta integración permite:
- 🔍 Inspeccionar acciones y el estado resultante.
- ⏪ Deshacer y rehacer cambios en el estado.
- 📈 Analizar el flujo de acciones en tiempo real.

## Instalación

### Paso 1: Instalar @ngrx/store-devtools
Ejecuta el siguiente comando en tu proyecto Angular: `bash npm install @ngrx/store-devtools`

### Paso 2: Configurar @ngrx/store-devtools en AppModule
Importa el módulo en AppModule:
```ts
import { StoreDevtoolsModule } from '@ngrx/store-devtools'; 
import { environment } from '../environments/environment';

@NgModule({ imports: [ 
    // Otros módulos... 
    StoreDevtoolsModule.instrument({ 
        maxAge: 25, // Número de estados a conservar en el historial 
        logOnly: environment.production // Restringe funciones en producción 
    }) 
] }) 

export class AppModule {} 
```
- **Explicación**:
    - **maxAge**: Define cuántos estados conservar en el historial. 
    - **logOnly**: Limita las funciones en modo producción para mayor seguridad.


### Paso 3: Instalar la extensión Redux DevTools
Abre tu navegador y busca la extensión Redux DevTools: Extensión para Chrome Extensión para Firefox Instala la extensión y asegúrate de que esté habilitada.

### Paso 4: Visualizar el flujo de acciones y estados
- Inicia tu aplicación Angular en el navegador. 
- Abre la extensión Redux DevTools desde las herramientas de desarrollo del navegador (Ctrl + Shift + I o F12). 
- Funcionalidades de Redux DevTools
    - **Acciones**: Lista de acciones despachadas en la aplicación. 
    - **Estado**: Estado del almacén después de cada acción. 
    - **Diff**: Cambios específicos en el estado tras cada acción. 
    - **Viaje en el tiempo**: Retrocede o avanza en el historial de acciones para probar estados anteriores.


## Ejemplo Práctico: Visualización del flujo de acciones
Imagina una aplicación que gestiona un carrito de compras:
- La acción AddItem se dispara al agregar un producto. 
- La acción RemoveItem se dispara al eliminar un producto. 
- Flujo en tiempo real:
    - [Cart] Add Item 
    - [Cart] Remove Item 
    - Cambios en el estado:
        - Antes: `{ items: [], total: 0 }`
        - Después: `{ items: [ { id: 1, name: 'Producto A' } ], total: 10 } `
    - Diagrama Representativo
        - Flujo de Depuración
            - Acción Despachada -> Estado Anterior -> Cambio -> Estado Actual Interfaz de Redux DevTools
    - Panel de Acciones (columna izquierda). 
    - Vista del Estado Actual (columna derecha). 
    - Botones para retroceder, avanzar y reiniciar el estado. 

## Configuración del Feature Store
Un Feature Store es una sección independiente del Store principal. Esta separación permite que la aplicación sea más escalable y modular, dividiendo la Store principal en pequeños módulos o features.

- **Ventajas** de un Feature Store
    - **Escalabilidad**: Facilita la escalabilidad de la aplicación. 
    - **Modularización**: Los módulos pueden ser independientes, reutilizables y mantenibles. 
    - **División de áreas**: Se aplica especialmente en aplicaciones grandes con múltiples áreas de negocio.
- **Comando para crear un Feature Store**
    - Para crear un Feature Store, se usa el comando: `ng generate feature usuarios --module app.module.ts`
- **Archivos creados** automáticamente:
    - `usuarios.actions.ts`: Archivo con las acciones. 
    - `usuarios.reducer.ts`: Archivo con el reducer. 
    - `usuarios.selectors.ts`: Archivo con los selectores. 
    - `usuarios.effects.ts` (opcional, si se usa Effects).
- **Configuración** en `app.module.ts`
    - Para que el Feature Store funcione, debe ser registrado `en app.module.ts` usando `StoreModule.forFeature()`.

### Pasos para registrar un Feature Store:
- Importar el `StoreModule` desde `@ngrx/store`. 
- Importar el reducer del Feature Store. 
- Registrar la Store con StoreModule.forFeature(). 

#### Ejemplo de configuración:
```ts
import { NgModule } from '@angular/core'; 
import { BrowserModule } from '@angular/platform-browser'; 
import { AppComponent } from './app.component'; 
import { StoreModule } from '@ngrx/store'; 
import { usuariosReducer } from './state/usuarios.reducer';

@NgModule({ 
    declarations: [AppComponent], 
    imports: [ 
        BrowserModule, StoreModule.forRoot({}), 
        StoreModule.forFeature('usuarios', usuariosReducer) 
    ], 
    bootstrap: [AppComponent] 
}) 
export class AppModule {} 
```
- **Explicación**:
    - Se usa StoreModule.forFeature('usuarios', usuariosReducer) para registrar la Store del módulo usuarios. 
    - La clave 'usuarios' se utiliza para identificar la Store. 
    - El usuariosReducer gestiona las acciones que afectan esta Store. 

## Acciones
Las acciones representan eventos que ocurren en la aplicación. Estos eventos pueden ser disparados por el usuario, una llamada a una API o cualquier evento interno.

### Componentes de una acción:
- Tipo (type): Define el nombre del evento. 
- Payload (opcional): Transporta datos asociados a la acción

### Crear Acciones con createAction
- Para crear una acción en NgRx, se usa la función createAction.
```ts
import { createAction, props } from '@ngrx/store';

export const cargarUsuarios = createAction('[Usuarios] Cargar Usuarios');
export const cargarUsuariosExitoso = createAction('[Usuarios] Cargar Usuarios Exitoso', props<{ usuarios: any[] }>()); 
export const cargarUsuariosError = createAction('[Usuarios] Cargar Usuarios Error', props<{ error: any }>()); 
```
- **Explicación**:
    - cargarUsuarios: Acción que se dispara cuando comienza la carga de usuarios. 
    - cargarUsuariosExitoso: Se ejecuta cuando la carga de usuarios se completa con éxito. 
    - cargarUsuariosError: Se ejecuta cuando hay un error al cargar los usuarios. 

## Reducers
Los reducers son funciones puras que toman el estado actual y una acción como entrada, y devuelven un nuevo estado.

### Funcionalidades de los Reducers:
Evaluar la acción recibida. Actualizar el estado de la aplicación de forma inmutable.

### Crear Reducers con createReducer
Para definir un reducer en NgRx, se usa la función createReducer.
```ts
import { createReducer, on } from '@ngrx/store'; 
import { cargarUsuarios, cargarUsuariosExitoso, cargarUsuariosError } from './usuarios.actions';

export interface UsuariosState { usuarios: any[]; cargando: boolean; error: any; }

export const estadoInicial: UsuariosState = { usuarios: [], cargando: false, error: null };

export const usuariosReducer = createReducer( 
    estadoInicial, 
    on(cargarUsuarios, (state) => ({ ...state, cargando: true })), 
    on(cargarUsuariosExitoso, (state, { usuarios }) => ({ ...state, cargando: false, usuarios })),
     on(cargarUsuariosError, (state, { error }) => ({ ...state, cargando: false, error })) 
); 
```
- **Explicación**:
    - Se define un estado inicial. 
    - Las acciones cargarUsuarios, cargarUsuariosExitoso y cargarUsuariosError actualizan el estado.
