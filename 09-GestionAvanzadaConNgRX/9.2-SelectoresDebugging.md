# Selectores y Debugging

## Uso de Selectores de Funciones
En Angular con NgRx, los selectores son herramientas poderosas para extraer y transformar datos del almacén de manera eficiente. Permiten que los componentes accedan únicamente a los datos que necesitan, reduciendo la lógica en la UI y mejorando el rendimiento de la aplicación.

## ¿Qué son los Selectors?
Un selector es una función que extrae datos del estado global o de un Feature Store. Angular proporciona APIs en NgRx para crear selectores reutilizables, lo que permite transformar los datos directamente desde el estado antes de que lleguen a los componentes.
- **Ventajas** de usar Selectores
    - 📦 **Reutilización de lógica**: Centralizan las transformaciones de datos.
    - ⚡ **Optimización de rendimiento**: Usan memoria caché para evitar cálculos innecesarios.
    - 🔧 **Modularidad**: Facilitan el mantenimiento al separar la lógica de transformación del componente.
- **Tipos de Selectores**
    - **Selector de Funciones**: Extrae un fragmento del estado global asociado a una Feature Store.
    - **Selector Memoizado**: Optimiza el acceso a datos al evitar cálculos repetidos con el mismo estado.
    - **Selector Compuesto**: Combina varios selectores para generar datos complejos a partir del estado.

## Ejemplo Práctico: Carrito de Compras
### 1️⃣ Definir el Selector de Funciones
- Un selector de funciones apunta a un segmento específico del estado global.

```typescript 
import { createFeatureSelector } from '@ngrx/store'; 
import { CartState } from './cart.reducer';

export const selectCartState = createFeatureSelector('cart'); 
```
- **Explicación**:
    - **selectCartState**: Accede al estado de la tienda cart desde el estado global.

### 2️⃣ Crear Selectores Personalizados 
- Los selectores personalizados extraen datos específicos de la Feature Store.
```typescript 
import { createSelector } from '@ngrx/store'; 
import { CartState } from './cart.reducer';

export const selectCartItems = createSelector( selectCartState, (state: CartState) => state.items );
export const selectCartTotal = createSelector( selectCartState, (state: CartState) => state.total ); 
```
- **Explicación**:
    - **selectCartItems**: Extrae la lista de productos del carrito. selectCartTotal: Calcula el total del carrito.

### 3️⃣ Usar los Selectores en un Componente 
En un componente Angular, puedes suscribirte a los selectores para acceder a los datos.
```ts
import { Component } from '@angular/core'; 
import { Store } from '@ngrx/store'; 
import { Observable } from 'rxjs'; 
import { selectCartItems, selectCartTotal } from './cart.selectors';

@Component({ 
    selector: 'app-cart', template: 
    <div *ngFor="let item of items$ | async"> 
        {{ item.name }} - {{ item.price | currency }} 
    </div> 
    <p>Total: 
        {{ total$ | async | currency }}
    </p> 
}) 

export class CartComponent { 
    items$: Observable<Product[]>; total$: Observable;

    constructor(private store: Store) { 
        this.items$ = this.store.select(selectCartItems); 
        this.total$ = this.store.select(selectCartTotal); 
    } 
}
```

### Flujo de Datos
Estado Global -> Selector (transformación de datos) -> Componente (UI) 

## Conclusión
Los Feature Selectors son herramientas esenciales para gestionar y optimizar el acceso a datos en aplicaciones Angular con NgRx. Con ellos, puedes centralizar la lógica de transformación, mejorar el rendimiento y simplificar los componentes. Este enfoque modular asegura que las aplicaciones sean más mantenibles y escalables.

## Herramientas de Depuración
Depurar el estado de una aplicación gestionada con NgRx puede ser desafiante, especialmente en proyectos grandes. Afortunadamente, `@ngrx/store-devtools` proporciona herramientas para visualizar y depurar el estado de la tienda en tiempo real. Estas herramientas permiten rastrear acciones, estados y efectos con facilidad, mejorando significativamente la experiencia de desarrollo.

## Conclusión
`@ngrx/store-devtools` y `Redux DevTools` son herramientas imprescindibles para depurar aplicaciones Angular con NgRx. Facilitan la visualización del estado y las acciones, mejorando la comprensión del flujo de datos y acelerando la solución de problemas. Con estas herramientas, puedes navegar a través del historial de estados y optimizar tu aplicación con confianza.
