# Effects en NgRx
En NgRx, los efectos son una herramienta clave para manejar tareas asíncronas, como llamadas a APIs o interacciones con servicios externos, sin sobrecargar la lógica de los componentes ni los reductores. Esto ayuda a mantener los componentes más puros y el código más organizado y mantenible.

## ¿Qué son los Efectos?
Los efectos son servicios que escuchan las acciones despachadas en la aplicación y ejecutan lógica adicional en respuesta a esas acciones. 
- Pueden despachar nuevas acciones al store o realizar operaciones como:
    - 🔗 Llamadas a APIs
    - 🗂️ Escritura en localStorage
    - 📊 Registro de eventos analíticos
- Ventajas de Usar Efectos
    - 🛠️ Centralizan la lógica de efectos secundarios.
    - 🔍 Facilitan la prueba y el mantenimiento del código.
    - 📦 Desacoplan tareas complejas de los componentes.
- ¿Cómo Funcionan los Efectos?
    - 🔥 Acción: Se despacha una acción desde el componente.
    - ⚙️ Efecto: El efecto intercepta la acción y ejecuta la lógica necesaria.
    - 💾 Store: El efecto envía una nueva acción para actualizar el estado con los resultados.

## Ejemplo Práctico: Llamada a una API
### 1️⃣ Definir las Acciones
```typescript 
import { createAction, props } from '@ngrx/store';

export const loadProducts = createAction('[Products] Load Products'); 
export const loadProductsSuccess = createAction( '[Products] Load Products Success', props<{ products: Product[] }>() ); 
export const loadProductsFailure = createAction( '[Products] Load Products Failure', props<{ error: string }>() ); 
```
**Explicación**:
- `loadProducts`: Acción que se despacha para cargar productos. 
- `loadProductsSuccess`: Acción que se despacha cuando la carga de productos es exitosa. 
- `loadProductsFailure`: Acción que se despacha si ocurre un error en la carga de productos.

### 2️⃣ Crear el Efecto 
```ts
import { Injectable } from '@angular/core'; 
import { Actions, createEffect, ofType } from '@ngrx/effects'; 
import { ProductService } from '../services/product.service'; 
import { loadProducts, loadProductsSuccess, loadProductsFailure } from './products.actions'; 
import { catchError, map, mergeMap } from 'rxjs/operators'; 
import { of } from 'rxjs';

@Injectable() 
export class ProductsEffects { 
    loadProducts$ = createEffect(() => this.actions$.pipe( ofType(loadProducts), 
    mergeMap(() => this.productService.getProducts().pipe( map(products => loadProductsSuccess({ products })), 
    catchError(error => of(loadProductsFailure({ error }))) 
    ) ) ) );

    constructor(private actions$: Actions, private productService: ProductService) {} 
} 
```
Explicación:
- `ofType`(loadProducts): Filtra las acciones para procesar solo las de tipo 
- `loadProducts. mergeMap()`: Ejecuta la llamada a la API y escucha los resultados. 
- `map()`: Despacha loadProductsSuccess con los datos obtenidos. 
- `catchError()`: Maneja errores y despacha loadProductsFailure. 

### 3️⃣ Configurar el Módulo de Efectos 
- Importa el módulo de efectos en tu aplicación y registra los efectos:
```ts
import { NgModule } from '@angular/core'; 
import { EffectsModule } from '@ngrx/effects'; 
import { ProductsEffects } from './products.effects';

@NgModule({ imports: [ 
    // Otros módulos... 
    EffectsModule.forRoot([ProductsEffects]) 
] }) 
export class AppModule {} 
```
**Explicación**:
- Se usa `EffectsModule.forRoot()` para registrar todos los efectos de la aplicación. 
- Se registra `ProductsEffects` en la raíz de la aplicación.

### 4️⃣ Usar los Datos en un Componente 
El componente puede interactuar con la tienda sin preocuparse por la lógica de la API.
```ts
import { Component, OnInit } from '@angular/core'; 
import { Store } from '@ngrx/store'; 
import { loadProducts } from './store/products.actions'; 
import { Observable } from 'rxjs'; 
import { Product } from './models/product.model';

@Component({ 
    selector: 'app-products', 
    template: <div *ngFor="let product of products$ | async"> {{ product.name }} - {{ product.price | currency }} </div> 
}) 
export class ProductsComponent implements OnInit { 
    products$: Observable<Product[]>;
    constructor(private store: Store) { 
        this.products$ = this.store.select(state => state.products.list)
    }
    ngOnInit(): void { 
        this.store.dispatch(loadProducts()); 
    } 
} 
```
Explicación:
- Se utiliza store.dispatch(loadProducts()) para cargar los productos. 
- Se accede al estado de products.list con store.select() para obtener la lista de productos. 
- Se usa async pipe para mostrar los datos en la plantilla de forma reactiva.

## Flujo de Efectos
- Componente 
    - ⬇️ Acción (loadProducts) 
    - ⬇️ Efecto (Effect) 
    - ⬇️ Llamada API 
    - ⬇️ Acción (loadProductsSuccess) 
    - ⬇️ Reductor (Reducer) 
    - ⬇️ Estado Actualizado 
    - ⬇️ UI (Interfaz de Usuario)

## Interacción entre Elementos
- El Componente despacha una Acción. 
- El Efecto realiza la llamada API y envía una nueva acción con los resultados. 
- El Reductor actualiza el estado. 
- La UI se actualiza automáticamente al cambiar el estado. 

## Conclusión
Los efectos en NgRx son esenciales para manejar tareas asíncronas de forma eficiente y mantener los componentes y reductores libres de lógica compleja.

## Beneficios Clave:
- 💡 Modularización de lógica compleja. 
- 🎉 Desacople de los componentes. 
- 🛠️ Manejo eficiente de errores. 
- 🔍 Facilidad de depuración y pruebas. 

> Con esta estructura, las aplicaciones Angular pueden gestionar tareas externas, como llamadas a APIs, de manera más limpia, organizada y escalable.
