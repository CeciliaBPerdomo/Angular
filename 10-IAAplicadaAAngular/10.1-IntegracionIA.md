## Configuración inicial de APIs de IA
Para integrar IA en un proyecto Angular, es esencial configurar correctamente las APIs que se utilizarán. A continuación, se explican los pasos clave.

### 1. Registro y obtención de credenciales
- Accede a la página oficial del proveedor de la API (por ejemplo, OpenAI o Google Cloud AI). 
- Regístrate y crea un nuevo proyecto en la consola de la API. 
- Genera una clave de API (API Key) que servirá como identificador único para tus solicitudes.

### 2. Instalación de dependencias
- Asegúrate de tener un proyecto Angular funcional y añade las bibliotecas necesarias. 
- Comando a ejecutar: 
    - `npm install axios`: esta dependencia te permitirá realizar solicitudes HTTP de forma sencilla.

### 3. Configuración del servicio Angular
- Es una buena práctica centralizar la interacción con la API en un servicio de Angular. 
- Este servicio gestionará la conexión con la API y la obtención de respuestas.
- Ejemplo de servicio Angular:
```ts
import axios from 'axios';

@Injectable({
  providedIn: 'root',
})

export class AiApiService {
  private apiUrl = 'https://api.openai.com/v1/engines/davinci/completions';
  private apiKey = 'TU_CLAVE_API';

  async getResponse(prompt: string): Promise<any> {
    try {
      const response = await axios.post(
        this.apiUrl,
        { prompt },
        { headers: { Authorization: `Bearer ${this.apiKey}` } }
      );
      return response.data;
    } catch (error) {
      console.error('Error al conectar con la API:', error);
      throw error;
    }
  }
}
```
- **Explicación** del servicio:
    - **apiUrl**: URL de la API de OpenAI para generar respuestas. 
    - **apiKey**: La clave API generada previamente. 
    - **getResponse()**: Método que se conecta con la API utilizando la biblioteca axios. 
    - **try-catch**: Captura errores que puedan ocurrir durante la solicitud.

### 4. Pruebas iniciales
- Para probar la conexión, crea un componente simple que consuma este servicio y muestre la respuesta en consola.
- Ejemplo de uso en componente Angular:
```ts
import { AiApiService } from './services/ai-api.service';

@Component({
  selector: 'app-chatbot',
  template: `<button (click)="consultarIA()">Consultar IA</button>`,
})
export class ChatbotComponent implements OnInit {
  constructor(private aiApiService: AiApiService) {}

  consultarIA() {
    this.aiApiService.getResponse('¿Cómo integrar IA?')
      .then(response => console.log('Respuesta de la IA:', response));
  }
}
```

#### Errores comunes y soluciones
Durante la integración de una API de IA, es posible que se presenten algunos problemas comunes. A continuación, se explican las posibles soluciones.

#### Error Causa posible Solución
- **Límites de solicitudes**: Exceso de solicitudes a la API Revisa los límites de tu plan en la consola de la API. 
- **Errores de autenticación**:  Clave API incorrecta o expirada Verifica que la clave API sea correcta y esté activa. 
- **Error de CORS**: Falta de configuración de CORS Configura CORS en la consola de la API o en el servidor. 
- **Timeout** en la solicitud: La API tarda demasiado en responder Implementa un timeout en la solicitud HTTP.
